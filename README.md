<h2 align="center"> 🚀 Featured Projects: </h2>

<h3 align="center"> Event-Based Temporal Action Detection </h3>

<div align="center">

🎯 **Improved reTAG — the only published action detection system built on event-camera data — without touching a single network weight.**
🛠️ **Tech Stack Used:** Python, PyTorch, OpenCV, NumPy
📈 **Impact:** mAP **0.5780 → 0.6604 (+8.24 points)** through Soft-NMS, Test-Time Augmentation, temperature scaling and adaptive percentile thresholding. Also diagnosed a score inversion in the base network and found a bug in the original authors' repository that affects their published results.
📄 **Follow-up (paper in preparation):** a continuous detector trained on the frozen encoder pushes it to **0.7776 mAP (+19.96 points)**, with **0.8422 under cross-validation with recording-disjoint folds**.

🔗 Check it out here 👉 **[event-penguins-optimization](https://github.com/pabloseijo/event-penguins-optimization)**

</div>

<h3 align="center"> Hexylon — Talking to RF Instruments in Plain Language </h3>

<div align="center">

🎯 **Built a system that lets engineers operate RF measurement equipment by just asking for it — no SCPI syntax required.** Developed in collaboration with **[Gsertel](https://www.gsertel.com)**.
🛠️ **Tech Stack Used:** Python, FastAPI, React 19, Ollama (local LLM), MCP, SCPI over TCP
📈 **Impact:** A local LLM pipeline drives a multi-instrument orchestrator that controls the **Hexylon RF meter** and an **R&S SGU100A generator**, with async tasks, automated frequency sweeps and a real-time web interface. The **MCP server runs inside the device itself**, acting as a strictly decoupled gateway between the instrument and the model — no business logic, just access.

🔗 Check them out here 👉 **[Hexylon LLM Client](https://github.com/pabloseijo/Hexylon-LLM-Client)** · **[Hexylon MCP](https://github.com/pabloseijo/Hexylon-MCP)**

</div>

<h3 align="center"> Castros IA — Finding Iron Age Hillforts with Deep Learning </h3>

<div align="center">

🎯 **End-to-end geospatial ML pipeline that scans Galicia for undiscovered Iron Age hillforts hidden under vegetation.**
🛠️ **Tech Stack Used:** Python, PyTorch, GDAL, rasterio, QGIS, LiDAR
📈 **Impact:** Multi-source ingestion (LiDAR, PNOA orthophotos, Sentinel-2), weak labelling, segmentation networks and a QGIS review queue. Validated on a **pre-registered held-out region** — northern Portugal, frozen twelve days before the test set was ever opened: **F1 0.284**, and **1 in 3 reviewed candidates is a real hillfort**.

🔗 Check it out here 👉 **[castros-ia-galicia](https://github.com/pabloseijo/castros-ia-galicia)**

</div>
